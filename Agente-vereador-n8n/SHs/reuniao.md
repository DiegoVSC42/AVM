## Briefing Reunião

Olá! Estou desenvolvendo um projeto com agentes de IA (construídos em n8n) e estou buscando um fornecedor para implementar a camada de aplicação (frontend + backend leve).

**Importante:** A API que fará o processamento das respostas ainda está em desenvolvimento, mas posso fornecer *endpoints simulados (mock)* para que o sistema seja construído normalmente.

O que preciso que seja desenvolvido:

**1. Sistema SaaS com:**

* Cadastro / Login de usuários (e recuperação de senha)
* Sistema de pagamento por assinatura (Stripe, Mercado Pago ou semelhante)
* Área do usuário com interface **intuitiva e focada em usabilidade**

**2. Fluxo principal do usuário (prototipável mesmo com API mock):**

1. Usuário preenche informações fixas sobre seu perfil
2. Escreve um tema ou ideia de conteúdo
3. O sistema envia esses dados para a API (mock)
4. A resposta é exibida como sugestão de post
