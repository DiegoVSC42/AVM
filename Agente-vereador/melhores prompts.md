# Melhores Prompts

## Carrosséis

Preciso que você gere um carrossel para instagram.

- Use linguagem simples e direta, sem juridiquês.
- Use meu perfil como base factual.
- O conteúdo deve seguir o melhor framework de comunicação para redes sociais (pas-i-cta ou aida), mas não explique o framework nem cite ele. Apenas reflita ele na estrutura dos textos.
- O conteúdo deve respeitar o tema abaixo e manter coerência entre as telas.

## Post para Instagram (Feed Único)

Preciso que você gere um post para Instagram em formato de texto único (não carrossel).

- Use linguagem simples e direta, sem juridiquês.
- Use meu perfil como base factual.
- O conteúdo deve ser compacto, com início chamativo, desenvolvimento objetivo e encerramento com chamada para ação.
- Aplique templates para post de Instagram (estrutura de abertura → contexto → mensagem central → CTA).
- Evite excesso de hashtags ou emojis — use apenas se forem estrategicamente relevantes.
- Se faltar algum dado, utilize {{inserir_dado_aqui}} como placeholder.

## Roteiro para Vídeo Curto (Reels / Shorts)

Preciso que você gere um roteiro para vídeo curto no formato de Reels ou Shorts.

- Use linguagem oral, simples e direta — como se eu estivesse falando para a câmera.
- Use meu perfil como base factual.
- O roteiro deve ter no máximo 30 a 45 segundos de duração.
- Estruture na lógica: abertura chamativa → desenvolvimento objetivo → fechamento com chamada para ação.
- Escreva em forma de fala, com marcações de pausa ou ênfase se necessário.
- Aplique templates de roteiro para vídeo curto.
- Se faltar algum dado, utilize {{inserir_dado_aqui}} como placeholder.

**TEMA DO VÍDEO ->**

## Stories (Sequência)

Preciso que você gere uma sequência de stories para Instagram.

- Use linguagem simples e direta, como se eu estivesse falando informalmente com quem me acompanha.
- Use meu perfil como base factual.
- Estruture em formato de narrativa rápida, com divisão sugerida em 3 a 5 partes (ex: introdução → contexto → mensagem principal → chamada para ação).
- Cada story deve ter uma ideia principal curta por tela.
- Aplique templates para stories, considerando variações entre texto falado, enquete, pergunta ou link.
- Se houver chamada para interação, utilize {{inserir_link_aqui}} ou {{inserir_caixinha_de_pergunta_aqui}} como placeholder.

## Mensagem de WhatsApp (Direta 1:1)

Preciso que você gere uma mensagem para WhatsApp no formato de conversa individual.

- Use linguagem próxima e acolhedora, como se estivesse falando diretamente com uma pessoa específica.
- Use meu perfil como base factual.
- Evite soar genérico — trate como diálogo pessoal.
- Aplique templates de WhatsApp para mensagem direta (saudação → ponto principal → convite para resposta).
- Se houver necessidade de encaminhamento, utilize {{inserir_contato_aqui}} ou {{inserir_link_aqui}} como placeholder.

**TEMA DA MENSAGEM DIRETA ->**

## Mensagem de WhatsApp (Lista de Transmissão / Coletiva)

Preciso que você gere uma mensagem para WhatsApp que será enviada em massa via lista de transmissão.

- Use linguagem respeitosa e cordial, mas não excessivamente pessoal (já que será enviada para várias pessoas).
- Use meu perfil como base factual.
- O conteúdo deve ser objetivo e com uma única mensagem central.
- Aplique templates de WhatsApp para comunicação coletiva (saudação opcional → informação principal → chamada para ação clara).
- Se houver link, formulário ou caminho de participação, utilize {{inserir_link_aqui}} como placeholder.

## Votações

Preciso que você gere uma peça de explicação de voto.

- Use meu perfil como base factual.
- O conteúdo deve refletir o formato padrão de explicação de voto para redes sociais.
- Mostre claramente qual foi o voto e o motivo, de forma coerente com minha ideologia e posição em relação à gestão.

## Mobilização Social

Preciso que você gere uma peça de mobilização social.

- Use linguagem simples e direta, sem juridiquês.
- Use meu perfil como base factual.
- O conteúdo deve incentivar a participação popular de forma respeitosa e coerente com minha atuação.
- O chamado para ação deve ser claro e possível de ser executado pelo público (ex: preencher um formulário, comparecer a um local, participar de uma audiência, enviar mensagem etc.).

**TEMA DA MOBILIZAÇÃO ->**

## Requerimentos ao Executivo

Preciso que você gere um requerimento ao Poder Executivo.

- Use linguagem técnica apenas quando necessária, mas mantenha o texto claro e objetivo.
- Use meu perfil como base factual.
- Estruture o requerimento de forma institucional, with uma justificativa fundamentada e um pedido específico e executável.
- Não ultrapasse os limites legais do papel do vereador; o pedido deve ser compatível com a função de fiscalizar e solicitar informações ou providências.
- Aplicar checklists de requerimento
- Utilizar templates de requerimento
- Se faltar algum dado essencial para o pedido, utilize placeholders no formato {{inserir_dado_aqui}} e me comunique o que falta.

**TEMA DO REQUERIMENTO ->**

## Fiscalização

Preciso que você gere uma peça de fiscalização.

- Use linguagem simples e direta, sem juridiquês.
- Use meu perfil como base factual.
- O conteúdo deve apresentar de forma clara o problema identificado e mostrar que estou cobrando providências de forma responsável e institucional.
- A crítica deve ser firme, mas sempre respeitosa e dentro dos limites legais do papel de vereador.
- Se o caso envolver órgãos específicos, mencione-os apenas se o agente tiver certeza — caso contrário, utilize {{inserir_orgao_aqui}} como placeholder.

**TEMA DA FISCALIZAÇÃO ->**

## Tribuna

Preciso que você gere um discurso para a Tribuna.

- Use linguagem formal, mas sem exageros ou juridiquês desnecessário.
- Use meu perfil como base factual.
- O discurso deve ter introdução, desenvolvimento e encerramento com chamado à responsabilidade do Executivo ou da sociedade, conforme apropriado.
- A fala deve refletir firmeza e autoridade, mas sempre com respeito institucional.
- Aplicar Checklist para tribuna
- Aplicar template de tribuna
- Se for necessário citar dados ou leis, use placeholders no formato {{inserir_dado_aqui}} ou {{inserir_lei_aqui}}.

## Tribuna (Posicionamentos)

Preciso que você gere um discurso de posicionamento para a Tribuna.

- Use linguagem firme e assertiva, porém respeitosa e institucional.
- Use meu perfil como base factual.
- O discurso deve deixar clara minha posição sobre o tema em questão — seja de apoio, crítica ou alerta.
- Argumente com coerência e chamando à responsabilidade os agentes envolvidos, mas sempre dentro dos limites legais do cargo de vereador.
- Aplicar Checklist para tribuna
- Se precisar mencionar autoridades, órgãos ou leis, utilize placeholders como {{inserir_autoridade_aqui}} ou {{inserir_lei_aqui}}.

**TEMA DO POSICIONAMENTO ->**

## Leis (Propor / Revogar)

Preciso que você gere uma peça sobre proposição ou revogação de lei.

- Use linguagem simples e direta, sem juridiquês excessivo.
- Use meu perfil como base factual.
- Deixe claro se a proposta é de criação, alteração ou revogação de lei.
- Explique de forma rápida o problema atual e como a proposta resolve ou corrige a situação.
- Se a lei ainda não existir ou o número ainda não estiver definido, utilize placeholders como {{inserir_numero_da_lei_aqui}}.
- Não prometa resultados que dependam exclusivamente do Executivo ou de terceiros — mantenha a fala dentro do papel legislativo.

**TEMA DA PROPOSTA DE LEI ->**

## Atendimento de Gabinete

Preciso que você gere uma peça sobre atendimento de gabinete.

- Use linguagem acolhedora e acessível, sem juridiquês.
- Use meu perfil como base factual.
- O conteúdo deve mostrar disponibilidade para ouvir a população e reforçar que o gabinete está aberto para receber demandas.
- O chamado para ação deve ser claro (ex: agendamento, endereço, WhatsApp ou formulário), mas apenas se essa informação estiver disponível — caso contrário, utilize {{inserir_forma_de_contato_aqui}}.
- Evite prometer solução imediata; destaque que o papel do gabinete é acolher, encaminhar e acompanhar.

## Orçamento

Preciso que você gere uma peça sobre orçamento público.

- Use linguagem simples e direta, sem juridiquês.
- Use meu perfil como base factual.
- O conteúdo deve traduzir os números orçamentários para o impacto real na vida das pessoas.
- Utilize comparações simples para facilitar o entendimento (ex: “o gasto com X equivale a Y escolas/postos de saúde/ônibus”).
- Se houver prioridade ou cenário comparativo, apresente ganhos e perdas de forma equilibrada.
- Caso seja uma peça interativa, finalize com chamada para participação popular (ex: enquete ou pedido de opinião).
- Se faltar informações financeiras específicas, use {{inserir_dado_orcamentario_aqui}} como placeholder.

**TEMA DO ORÇAMENTO ->**

## Defesa de Ideologia (Pautas Sensíveis)

Preciso que você gere uma peça de defesa de posicionamento ideológico sobre tema sensível.

- Use linguagem firme, mas respeitosa — sem atacar pessoas ou grupos.
- Use meu perfil como base factual.
- O posicionamento deve ser sustentado por pelo menos um dado objetivo (estatística, comparação ou fato histórico).
- A argumentação deve sempre levar ao benefício prático da postura defendida, conectando com a vida real das pessoas.
- Finalize com convite para debate respeitoso, sem polarizar.
